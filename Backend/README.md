# IceCream Shop Backend

Express API for the IceCream Shop application.

## Setup

From this directory:

```bash
npm install
```

## Run

Start the server with automatic restarts during development:

```bash
npm run dev
```

Or start it normally:

```bash
npm start
```

The server listens on port `3000` by default. Set `PORT` to use a different
port.

## Health check

`GET http://localhost:3000/api/health`
